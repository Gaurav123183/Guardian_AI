IBM Bob Technology Usage in Guardian AI

IBM Bob was used as an AI-assisted development tool during the development of Guardian AI. It supported the team throughout different stages of the project, including understanding requirements, planning features, developing application components, improving the user interface, debugging, and refining the overall implementation.

The team used IBM Bob to assist with the development of the Guardian AI web application and to understand how different components of the system could be connected. It helped in working with the frontend technologies such as HTML, CSS, and JavaScript, as well as the Python and Django backend. IBM Bob was also used to assist in understanding and refining the interaction between the frontend, backend, GPS functionality, routing services, and emergency-related modules.

During the development of the Safe Route module, IBM Bob was used as an AI-assisted coding and problem-solving tool to help structure the route-processing workflow, understand API communication, and refine the presentation of multiple alternative routes and their safety parameters. The team used it to assist in implementing and improving features such as route comparison, Safety Score, Risk Score, recommended route display, map interaction, and responsive interface behaviour.

IBM Bob was also used during the development and refinement of the GPS Guardian functionality. It assisted the team in understanding location-related workflows and organizing the interaction between GPS information and the application. This helped in developing the functionality for monitoring user location, movement, speed, and direction during a journey.

For the Bluetooth Safety feature, IBM Bob was used to assist in understanding the required development workflow and integrating Bluetooth-based interaction with the safety functionality. The feature was designed to provide an additional mechanism through which a compatible external safety device can interact with the application and support emergency assistance.

IBM Bob was also used during debugging and troubleshooting. When issues occurred in the application, the team used AI-assisted suggestions to identify possible causes, understand errors, refine code, and improve the implementation without changing unrelated project functionality. It was particularly useful during UI refinement, responsive design improvements, button behaviour, navigation, API integration, and feature-level testing.

The team also used IBM Bob to improve the clarity and usability of the application. Suggestions were used to refine layouts, feature descriptions, route information, navigation elements, and user interaction so that the safety-related information could be understood easily by users.

IBM Bob additionally supported documentation and project preparation. It helped the team organize technical explanations, describe system workflows, prepare project documentation, and communicate the purpose and functionality of Guardian AI in a clearer manner.

The overall development workflow can be summarized as:

Requirement Understanding → AI-Assisted Planning → Code Development → Feature Integration → Debugging → Testing → UI Refinement → Documentation

IBM Bob was therefore used as an AI-assisted development and productivity tool rather than as a replacement for the development team. The team reviewed, tested, modified, and integrated the generated suggestions according to the actual requirements of Guardian AI.

Through the use of IBM Bob, the team was able to accelerate development, explore implementation approaches, troubleshoot technical issues, improve the application's usability, and better organize the different components of the Guardian AI platform. The final system combines safety-aware route selection, GPS-based journey monitoring, Bluetooth-enabled safety interaction, and emergency communication into a unified platform focused on creating practical social impact.
